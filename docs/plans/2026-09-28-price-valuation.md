# 行情与钱包估值

用户要求实时价格与到账钱包总价值，沿用清爽浅色设计。

- 免费 CoinGecko simple/price，以明确币种 ID pearl-2 / nockchain 查询，返回 USD、CNY、24h 变化和报价时间。
- 云端五分钟采集的快照增加行情兜底；打开页面时每 60 秒尝试直连刷新，手动刷新最短间隔 15 秒。行情源可能缓存、延迟或限流，显示真实报价时间并保留可辨识的缓存。
- 顶部估值为当前钱包余额乘对应报价之和，各币种也显示单独估值；矿池余额和累计历史到账不用于这个合计。
- 未知余额或缺失价格不当作零。只有部分币种可计算时显示部分估值；没有可计算数据则显示未知。过期报价与余额同样有提示。
- 验证 ID/单位/时间戳、正负涨跌、未知和过期场景、USD/CNY 计算、手机布局，再发布并检查真实公网数据。
