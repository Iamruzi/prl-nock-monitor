# PRL / NOCK 个人监控页

用户要求：同一个页面查看两种币的钱包到账与矿工状态；免费托管、公网访问；清爽浅色，重点突出余额和状态。

## Implementation

1. 使用 Python 标准库并行查询 Pearlhash PRL 账户、独立 NOCK 账本、prlscan 地址及最近交易、nockscan 地址。规范金额单位和累计转入含义，只输出白名单字段。验证：真实接口样本及金额、异常、找零相关单元测试。
2. 独立 HTML/CSS/JS 页面，突出钱包余额、累计外部转入、矿池累计付款、待付款和待成熟。在线状态按矿池报告判断，不声称直接读取服务器运行状态。验证：桌面、手机、空状态、错误和过期状态的浏览器测试。
3. GitHub Pages + GitHub Actions 公共仓库标准 runner。每五分钟尝试采集并发布，页面每分钟读取最新快照；定时可能延迟，以更新时间为准。月度维护提交防止公共仓库 60 天无活动导致定时停用。验证：公网页面、真实自动化运行、独立重新采集。

## Boundaries

- 静态站点不能直接跨域读取 Pearlhash；由 Actions 采集解决，无需开放矿机端口或保存 SSH 凭据。
- 公开信息限两种公钥地址、余额、交易、矿池报告的矿工名、版本、显卡型号和算力。过滤矿池 worker IP、内部 ID、原始日志。
- 请求失败保留上一次成功的数据并显示过期状态；无旧值显示未知，不伪装成零。
- Nockscan 的明确 Address not found 响应显示「浏览器暂无记录」，不宣称钱包余额已经得到链上核验。
- PRL 累计外部转入使用 external_received_grains，避免把找零计作到账。矿池付款记录不等同于链上到账证明。
- 付款门槛使用已核实的规则，显示核实日期，可通过 config.json 更新。
